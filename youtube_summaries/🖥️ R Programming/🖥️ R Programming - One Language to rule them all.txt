🖥️ R Programming - One Language to rule them all
1. Introdução ao projeto One language to rule them all e estrutura dos problemas da Maven Analytics.
2. Visualização de redes hierárquicas organizacionais utilizando recursividade e diagrammR.
3. Manipulação de dados JSON e exploração de estruturas aninhadas com o pacote jsonlite.

9. Processamento de posições esportivas no beisebol através da divisão e contagem de strings.
10. Cálculo de totais de vendas baseados na junção de transações com histórico de preços dinâmico.
